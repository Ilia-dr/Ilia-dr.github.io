Apps Script Fleet

Личный инструмент для управления собственными проектами Google Apps Script с использованием официального Google Apps Script API и ограниченных рабочих процессов GitHub Actions.

Назначение

Инструмент помогает владельцу просматривать свои Apps Script проекты, историю выполнений, исходные файлы и версии, а также выполнять отдельно подтверждённые операции управления кодом и публикациями. Доступ осуществляется только после авторизации аккаунта Google с необходимыми OAuth-разрешениями.

Эта страница является информационной. Она не предоставляет публичную регистрацию, не принимает OAuth-токены и не запускает автоматизации.

Как используются Google API

В зависимости от одобренных владельцем операций используются Google Apps Script API для управления проектами и просмотра процессов, а также ограниченное чтение метаданных Google Drive для поиска принадлежащих аккаунту скриптов.

Авторизационные данные используются защищённым исполнителем и не публикуются на этом сайте. Выполнение функций скриптов использует отдельную схему авторизации с дополнительными ограничениями.

Правила и связь

Описание обработки данных — в политике конфиденциальности. Прочитайте также условия использования. По техническим вопросам можно обратиться через профиль разработчика на GitHub; не отправляйте туда токены, персональные данные или секреты.

Приложение не является официальным продуктом Google или GitHub. Сайт не использует Google Sign-In в браузере.
