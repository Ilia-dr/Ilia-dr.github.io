Политика конфиденциальности

Редакция: 10 ноября 2026 года

Apps Script Fleet — личная интеграция владельца, а не общедоступный сервис. Эта политика описывает обработку данных Google, доступных по явно предоставленным разрешениям.

1. Какие данные доступны

По разрешениям владельца приложение может получать метаданные проектов Google Apps Script, список и содержимое файлов скриптов, версии, сведения о публикациях и процессах выполнения. Для инвентаризации может получать ограниченные метаданные Google Drive. Управляющие операции могут изменять исходные файлы, версии или публикации только по отдельно подтверждённым запросам.

2. Для чего используются данные

Исключительно для инвентаризации, диагностики, резервного копирования, обновления и администрирования собственных Apps Script проектов владельца. Доступ не используется для рекламы, продажи пользовательских данных или профилирования.

3. Как обеспечивается доступ

Авторизация происходит через Google OAuth. Учётные данные Google OAuth хранятся в защищённых GitHub Actions Secrets приватного репозитория исполнителя; этот публичный сайт их не получает и не хранит. Доступ к функции исполнения скриптов ограничен отдельными разрешениями и дополнительными программными проверками.

4. Хранение и передача

Служебные сведения о результатах операций и ошибках могут сохраняться в приватном GitHub-репозитории для проверки, без копирования OAuth-секретов в опубликованные файлы. Резервные копии исходного кода скриптов создаются в закрытых артефактах GitHub Actions с настроенным сроком хранения до 3 дней. При этом Google обрабатывает API-запросы, а GitHub обеспечивает выполнение рабочих процессов и хранение их технических результатов. Содержимое исходников может включать информацию, добавленную владельцем в свои скрипты; поэтому резервные копии не публикуются.

5. Отзыв доступа и удаление

Владелец может отозвать предоставленные Google OAuth разрешения в настройках своего Google-аккаунта. При отзыве интеграция утратит соответствующий доступ. Результаты и резервные артефакты удаляются или перестают храниться согласно настройкам приватного GitHub-репозитория и срокам хранения GitHub Actions. Для отдельного удаления доступных данных следует обратиться к разработчику.

6. Публичный сайт

Эти статические страницы не содержат форм авторизации, сторонних виджетов, аналитических счётчиков, рекламных трекеров или собственного механизма cookies. GitHub Pages как хостинг может обрабатывать технические данные запросов согласно своим условиям.

7. Связь и изменения

Техническая связь: профиль владельца на GitHub; для вопросов о разрешениях можно использовать контактную почту приложения, указанную на экране согласия Google OAuth. Не публикуйте в обращениях пароли, refresh-токены и другие секреты.

Политика обновляется при существенном изменении разрешений, способов обработки или хранения Google-данных.
